# 人生漫旅活動報名工具操作說明

本工具用來建立活動、分享報名連結及統計參加者，不會取得或改變 LINE 社群的管理權限。

正式網站：`https://line-event-rsvp.james594007.workers.dev`

| 用途 | 網址 | 使用者 |
| --- | --- | --- |
| 申請使用活動工具 | https://line-event-rsvp.james594007.workers.dev/mod-apply | 第一次使用的活動發起人 |
| 活動管理工具 | https://line-event-rsvp.james594007.workers.dev/mod | 已開通的活動發起人 |
| 工具管理後台 | https://line-event-rsvp.james594007.workers.dev/owner | James Lee |

日常開團只需要使用「活動管理工具」網址。申請核准一次後，未來不必重複申請；登入狀態過期時只要重新使用 LINE 登入即可。

## 一、第一次開通活動工具

1. 將「申請使用活動工具」網址傳給活動發起人。
2. 對方開啟網址，按下「申請使用活動工具」，並用自己的 LINE 帳號登入。
3. 畫面顯示「等待開通」後，請對方通知 James Lee。
4. James Lee 開啟「工具管理後台」，在「待審核」名單中核准申請。
5. 對方重新開啟「活動管理工具」，即可建立活動。

建議傳給申請人的訊息：

> 這是活動建立與報名統計工具，不是申請 LINE 社群管理權。請用 LINE 登入申請使用：  
> https://line-event-rsvp.james594007.workers.dev/mod-apply

## 二、之後如何開團

已開通的使用者不必再次申請，直接開啟：

https://line-event-rsvp.james594007.workers.dev/mod

若系統要求登入，使用原本核准的 LINE 帳號登入即可。登入狀態目前保留 7 天；過期後重新登入不會重新進入審核。

## 三、建立活動

1. 進入「活動管理工具」。
2. 填寫主題、活動日期、活動地點等資料。
3. 視需要填寫集合地點、集合時間、費用、人數上限、報名截止時間、活動群連結及備註。
4. 視活動需求勾選：
   - 參加類型
   - 車輛（開車／共乘）
   - 攜伴人數
5. 按下「建立活動」。
6. 複製系統產生的報名連結，貼到 LINE 社群或對話中。

建立活動不會自動在任何 LINE 社群或對話中發文，只有主動分享報名連結後，其他人才會看到。

分享連結時會顯示：

- 社群名稱「人生漫旅FB社團Line社群」
- 活動主題
- 活動地點
- 活動日期

## 四、參加者如何報名或修改

1. 參加者開啟活動報名連結。
2. 選擇活動提供的報名項目。
3. 按下「我要參加」，並用 LINE 登入完成報名。
4. 在報名截止前，參加者可再次開啟同一連結修改或取消自己的報名。
5. 報名截止後，頁面只供查看，所有報名、修改與取消功能都會停止。

## 五、管理參加者

在「活動管理工具」的活動列表中按「查看名單」，可以：

- 查看參加者及攜伴人數。
- 修改參加類型、車輛角色或攜伴人數。
- 移除參加者。
- 恢復已取消或已移除的報名。
- 複製名單文字。
- 匯出 CSV 名單。

移除採用可恢復方式，不會立刻永久刪除紀錄。

## 七、重要提醒

- 請使用 `https://line-event-rsvp.james594007.workers.dev/...` 開頭的正式網址。
- 不要直接開啟電腦裡的 `public/mod.html`；本機 HTML 無法載入正式資料。
- 報名連結可以被轉貼到其他對話。社群名稱會顯示在預覽及報名頁，但目前不會驗證瀏覽者是否為該 LINE 社群成員。
- 不要在活動內容中填寫密碼、憑證、身分證字號或其他不必要的敏感資料。
- 若使用者換了另一個 LINE 帳號，系統會視為不同身分，需要重新申請。

## 八、最簡單的日常流程

活動發起人：

1. 開啟活動管理工具。
2. 用 LINE 登入。
3. 建立活動。
4. 把報名連結貼到社群。
5. 回到活動管理工具查看名單。

工具管理者：

1. 只有收到新申請通知時，才需要開啟工具管理後台。
2. 核准或拒絕申請。
3. 日常不需要介入活動建立與報名管理。
